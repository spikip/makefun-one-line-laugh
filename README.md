# One Line, One Laugh

A one-line joke, written by a small Python program to `/output/entry.txt`:

> My therapist says I use humor to deflect. I told her that's the cheapest coping mechanism with a five-star rating.

## Run

From the repository root:

```
python3 main.py
```

This writes the line (114 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).

## About this entry

The joke is built like a therapy session with the roles reversed.
The therapist opens with a perfectly clinical observation — humor
as deflection — and instead of denying it, the patient agrees
and files it under product reviews. Calling a coping mechanism
"the cheapest with a five-star rating" turns a diagnosis into a
recommendation, which is exactly how deflection works: the moment
you name the trick, the trick has already done its job. It stays
warm rather than bitter because the patient is not hiding from the
therapist at all; they are showing her the mechanism, rating it,
and inviting her to laugh at the review. Therapy, but make it a
punchline that both sides can enjoy.
